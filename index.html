Do DoorDash promo codes work for existing users?

Yes, but existing users rarely get a public sitewide code. Most existing user savings come from the Offers tab, merchant promotions and DashPass benefits.

How do I enter a DoorDash promo code?

Go to checkout, open Enter Promo Code or Promo codes, rewards and gift cards, enter the code exactly as shown, tap Apply, and check the total before you place the order.

Why is my DoorDash promo code not working?

The most common reasons are account targeting, a minimum spend that is not met on subtotal, a code that was already used, an excluded restaurant or item, or an expired offer. Check the condition message at checkout.
